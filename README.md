****Tenant Finder - Real Estate Management System**
Project Overview
Tenant Finder is a web-based Real Estate Management System developed to simplify the process of property listing, renting, and purchasing. The platform connects property owners, tenants, and customers through a user-friendly interface and provides efficient property management features.
**Features**
**Owner Module**
Owner Registration and Login
Add New Property Listings
Upload Property Images
Upload Tax Slip and Payment Receipt
Manage Property Details
View Property Status
**Tenant Module**
Browse Rental Properties
Search Properties by Location
View Property Details
Contact Property Owners
**Customer Module**
Browse Properties for Sale
View Property Information
Contact Property Owners
Purchase Property Listings
**General Features**
Secure User Authentication
Property Image Upload
Responsive User Interface
Property Search and Filtering
Property Reviews and Ratings
Google Maps Location Support
